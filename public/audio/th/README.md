# ไฟล์เสียงพูดภาษาไทย (Hybrid Audio Fallback)

วางไฟล์เสียง `.mp3` สำหรับประโยคคงที่ไว้ในโฟลเดอร์นี้ (`public/audio/th/`) เพื่อให้ระบบเสียงบนมือถือ iOS และ Android เล่นเสียงภาษาไทยที่คมชัดและสม่ำเสมอเหมือนกันทุกเครื่อง หากยังไม่มีไฟล์ใด ระบบจะสลับไปใช้ Web Speech API (`th-TH`) ให้อัตโนมัติ

รายชื่อไฟล์ที่รองรับ (ตรงกับ `AUDIO_CLIP_MAP` ใน `src/services/voiceService.js`):
- `scan.mp3` — แตะที่ไหนก็ได้ของหน้าจอ เพื่อสแกนเข้าสู่หน้า ไทยไอดี
- `scan_loading.mp3` — กำลังสแกน เล็งกล้องไปที่คิวอาร์โค้ด
- `scan_gallery.mp3` — กำลังอ่านรูปคิวอาร์โค้ด
- `scan_ok.mp3` — สแกนสำเร็จ
- `thaid.mp3` — กรุณาเข้าสู่ระบบด้วย ไทยไอดี
- `checkin.mp3` — กรุณากรอกรหัสเช็คอินสี่หลัก
- `checkout.mp3` — ใส่รหัสสี่หลัก พูดทีละตัวเลขได้เลยหลังเสียงนี้จบ หรือกดปุ่มตัวเลข
- `checkout_general.mp3` — กรุณากรอกรหัสเช็คเอาท์สี่หลักเพื่อรับใบเกียรติบัตร
- `checkout_wait.mp3` — ยังไม่ถึงเวลากรอกรหัสเช็กเอาต์ กรุณารอให้ครบเวลาเรียนก่อน
- `phone.mp3` — แตะปุ่มไมค์ตรงกลางหน้าจอ เพื่อพูดเบอร์มือถือ
- `phone_edit.mp3` — พูดเบอร์ใหม่ได้เลย
- `carrier_intro.mp3` — ยืนยันเบอร์แล้ว แตะมุมจอที่เป็นเครือข่ายของคุณ...
- `cert.mp3` — กำลังรับใบเกียรติบัตร
